# 📁 Pengumpulan Project 1 - Desain Dashboard Website

Repositori ini digunakan untuk mengumpulkan project pembuatan desain dashboard website.

---

## 📌 Aturan Struktur Folder

Setiap mahasiswa/siswa **wajib membuat folder dengan nama masing-masing**, lalu di dalamnya berisi beberapa template website dengan format penamaan:

* `template_1`
* `template_2`
* `template_3`
* dan seterusnya

---

## 🗂️ Contoh Struktur Direktori

Struktur yang benar:

```
pengumpulan-template/
│
├── amins_project/
│   ├── template_1/
│   ├── template_2/
│   └── template_3/
│
├── alan/
│   ├── template_1/
│   └── template_2/
│
└── README.md
```

---

## 📋 Ketentuan

* Nama folder utama menggunakan **nama masing-masing (tanpa spasi, disarankan lowercase)**
  Contoh: `amins_project`, `alan`
* Setiap template harus berada dalam folder terpisah
* Format nama template wajib:

  * `template_1`
  * `template_2`
  * dan seterusnya
* Isi template bebas (HTML, CSS, JavaScript, assets, dll)

---

## 🚀 Cara Upload

1. Clone repository:

   ```bash
   git clone https://github.com/aminsproject-dev/dashboard-template.git
   ```

2. Masuk ke folder project:

   ```bash
   cd dashboard-template
   ```

3. Tambahkan folder sesuai nama kamu, lalu isi dengan template

4. Commit dan push:

   ```bash
   git add .
   git commit -m "feat : add dashboard template [EXAMPLE]"
   git push origin main
   ```

---

## ⚠️ Catatan

* Jangan mengubah folder milik orang lain
* Pastikan struktur folder sesuai aturan
* Periksa kembali sebelum push
